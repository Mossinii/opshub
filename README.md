# OpsHub

OpsHub is a fictional operations portal built as a hands-on DevOps learning project.

The project focuses on:

- Linux administration
- Networking fundamentals
- Containers
- Automated testing
- CI/CD
- Monitoring and observability
- Kubernetes
- Infrastructure as Code
- Incident response

All systems, services, data, and runbooks in this project are fictional.

## Current status

Project initialization.

## Planned stages

1. Linux and networking fundamentals
2. Application containerization
3. Automated tests
4. CI pipeline
5. Monitoring with Prometheus and Grafana
6. Kubernetes deployment
7. Infrastructure as Code
8. Incident simulation and post-mortem
